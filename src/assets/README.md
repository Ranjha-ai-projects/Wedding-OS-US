# Wedding OS Assets Directory

All media and static assets for Couple OS are unified here.

## Folders Guide

### 1. `songs/`
- **Copy your songs here!**
- Supported formats: `.mp3`, `.wav`, `.m4a`, `.ogg`, `.flac`.
- **Automatic & Dynamic**: Any audio file placed here will immediately appear in the Music Player playlist.
- No hardcoded tracks: only the real songs in this folder will be played!
- If you add more songs in the future (e.g. `song4.mp3`, `first_dance.mp3`), they will automatically be discovered, formatted, and added to the player.

### 2. `gallery/`
- **Copy your photos here!**
- Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`, `.avif`.
- **Automatic & Dynamic**: Any photo placed here will immediately appear in the Photos App gallery and Story slideshow.
- Titles are automatically formatted from the file name.

### 3. `images/`
- Wallpapers and hero media:
  - `hero-couple.jpg` (Home screen and intro)
  - `lock-portrait.jpg` (Lock screen)
  - `proposal.jpg` (Proposal moment)

### 4. `icons/`
- System icons and favicon:
  - `favicon.svg`
  - `icons.svg`
